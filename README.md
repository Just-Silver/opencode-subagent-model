# opencode-subagent-model

给 OpenCode V2 的所有子代理统一指定模型，并在工具返回中告知主代理。
独立于供应商目录和 HUD，可选择当前目录可用的任意聊天模型。

> 当前为待发布的 `0.1.0-beta.0`，尚未发布 npm；现在请用本地目录加载。

## 安装

### 当前：本地目录加载

在 OpenCode 配置中添加插件源码目录的**绝对路径**：

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    { "package": "D:/Code/Projects/Agents/opencode-subagent-model/plugin/opencode-subagent-model" }
  ]
}
```

路径按实际位置修改。不需要安装脚本或先执行 `npm install`。

### npm 发布后

首次预发布可通过以下方式安装（当前尚不可用）：

```bash
opencode plugin add @justsilver/opencode-subagent-model@next
```

不要同时保留本地目录和 npm 配置，它们是同一个插件 ID。新增插件或更新 TUI 代码后，完全退出并重新启动 TUI。

## 使用

在输入框输入 `/`，从补全菜单选择 `/subagent-model`，或在命令面板搜索「子代理统一模型」。

- 选择聊天模型，再选择默认参数或变体；取消任一步都不会保存。
- 「关闭强制覆盖」恢复 OpenCode 原有模型选择规则。
- 设置在同一 OpenCode 服务端数据库下全局共享，重启后保留；保存后对后续调用生效。
- 启用时，无论主代理是否显式指定其他模型，前台、后台及续接调用都会被覆盖。
- 模型不可用或存储读取失败时明确报错，不静默回退。
- 工具成功返回末尾附本次强制模型标记；前台随完成结果、后台随启动确认返回。格式与边界见[策略契约](docs/subagent-model-policy.md#主代理知情边界)。

保存策略本身无需重启；已派发请求不会被新设置追溯修改。

## 从 providers 内置版本迁移

`opencode-providers@0.4.0-beta.0` 曾内置本功能。**远端撤包不会移除你本机已安装的副本或正在运行的 TUI 代码。**

1. 记录原先选择的模型及变体。
2. 先停用旧覆盖，并将 providers 切回已发布的稳定版 `0.3.4`，或使用已移除子代理功能的新源码。
3. 添加本插件，然后完全退出并重新启动 TUI，避免旧命令和新命令并存。
4. 用 `/subagent-model` 重新选择一次模型。

新插件使用独立存储命名空间，不自动读取、改写或删除旧设置。不需要为了使用本插件安装 providers 或 HUD。

## 疑难解答

| 现象 | 处理 |
|---|---|
| 找不到命令 | 检查插件加载状态、路径和是否完全重启了 TUI |
| 提示功能不可用 | 当前宿主缺少所需工具钩子，或钩子注册失败；不会假装保存成功 |
| 当前模型不可用 | 切到可用模型或关闭覆盖；不会静默换成其他模型 |
| 命令重复、模型覆盖冲突 | 检查是否仍加载旧 providers beta，或同时启用了本地和 npm 两份本插件 |
